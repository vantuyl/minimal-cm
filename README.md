# Minimal Cohen–Macaulay independence complexes that fail to be shellable or vertex decomposable

This repository accompanies the paper

> Adam Van Tuyl, *Minimal examples of Cohen–Macaulay independence complexes that fail to be shellable or vertex decomposable* (2026).

**Web page:** https://vantuyl.github.io/minimal-cm/ — the eight graphs, rotating pictures of their independence complexes, and the data below.

## The result

For any simplicial complex, vertex decomposable ⇒ shellable ⇒ Cohen–Macaulay.
A census of all 1,006,700,565 connected graphs on 11 vertices shows that 11 is the
smallest number of vertices for which either implication fails for an independence complex Ind(*G*):

- If char 𝕂 ≠ 2, exactly two graphs, *G*<sub>1</sub> and *G*<sub>2</sub>, have Ind(*G*) Cohen–Macaulay but not shellable.
- Exactly six graphs, *H*<sub>1</sub>, …, *H*<sub>6</sub>, have Ind(*G*) shellable but not vertex decomposable.
- If char 𝕂 = 2, then for every graph on 11 vertices, Ind(*G*) is Cohen–Macaulay if and only if it is shellable.

| Graph | graph6 | Property of Ind(*G*) |
|---|---|---|
| *G*<sub>1</sub> | `JCpdUg{[ap_` | CM (char ≠ 2), not shellable |
| *G*<sub>2</sub> | ``JCp`eikYa|?`` | CM (char ≠ 2), not shellable |
| *H*<sub>1</sub> | ``JCQdarc]`y?`` | shellable, not vertex decomposable |
| *H*<sub>2</sub> | ``JCQdarSZ`]?`` | shellable, not vertex decomposable |
| *H*<sub>3</sub> | `JCQbcvWZBM?` | shellable, not vertex decomposable |
| *H*<sub>4</sub> | `JCQbcvWZ@]?` | shellable, not vertex decomposable |
| *H*<sub>5</sub> | `JCQbcvWZBL?` | shellable, not vertex decomposable |
| *H*<sub>6</sub> | ``JCQbRb[f`y?`` | shellable, not vertex decomposable |

In each graph6 code, vertex *i* of the paper corresponds to vertex *i* − 1.

## Data

The folder `data/` lists every connected graph on *n* vertices whose independence complex is
Cohen–Macaulay over ℚ. Each file has one graph per line, in
[graph6 format](https://users.cecs.anu.edu.au/~bdm/data/formats.html), sorted.

| *n* | Cohen–Macaulay graphs | File |
|---:|---:|---|
| 2 | 1 | `data/cm_n2.txt` |
| 3 | 1 | `data/cm_n3.txt` |
| 4 | 2 | `data/cm_n4.txt` |
| 5 | 5 | `data/cm_n5.txt` |
| 6 | 20 | `data/cm_n6.txt` |
| 7 | 82 | `data/cm_n7.txt` |
| 8 | 565 | `data/cm_n8.txt` |
| 9 | 5,688 | `data/cm_n9.txt` |
| 10 | 102,039 | `data/cm_n10.txt` |
| 11 | 3,247,490 | `data/cm_n11.txt` (39 MB) |

Each file also comes in a gzip-compressed copy, `data/cm_nN.txt.gz`.

The counts for *n* ≤ 10 agree with Baker, Vander Meulen and Van Tuyl,
*Shedding vertices of vertex decomposable well-covered graphs*, Discrete Math. **341** (2018), 3355–3369.

### Reading the files in Macaulay2

```
needsPackage "Nauty";
R = QQ[x_1..x_11];
L = lines get "cm_n11.txt";            -- one graph6 string per line
I = stringToEdgeIdeal(first L, R);     -- edge ideal of the first graph
```

## How the census was done

The census was run twice, independently:

1. **2022–23:** Macaulay2 (packages EdgeIdeals, Nauty, SimplicialDecomposability) on the
   Digital Research Alliance of Canada clusters.
2. **2026:** separate Python code, with graphs generated by nauty's `geng`. This run also counted
   well-covered graphs (7,797,877 for *n* = 11, matching OEIS
   [A222625](https://oeis.org/A222625)).

Both runs tested Cohen–Macaulayness over ℚ, and both found the same eight graphs.
